# FAST_TABLES.md — быстрые таблицы AutoCAD

**Актуально для `MARK.lsp`.** Используется для ведомости профилей, ведомости
заполнений, закладных и условных обозначений.

## 1. Проблема

`AcDbTable` пересобирается при каждом изменении. Заполнение «ячейка за
ячейкой» на 160 строк — тысячи полных пересборок; таблица появляется минутами.

## 2. Метод

1. `AddTable` сразу на **конечное** число строк/столбцов.
2. `RegenerateTableSuppressed` = `:vlax-true`.
3. Заполнить все ячейки (`SetText`, `SetCellAlignment`, объединения).
4. `RegenerateTableSuppressed` = `:vlax-false`.
5. **Не вызывать** `vla-Update` / `Regenerate`.

Длинная ведомость режется на таблицы по `*mk:tab-ideal-rows*`; каждая таблица
создаётся конечного размера.

## 3. Где в коде

- `mk:tab-draw-all` — ведомость профилей.
- `mk:acc-table-create` — закладные.
- `mk:leg-table-create` — условные обозначения.
- `mtab:*` — ведомость заполнений.

## 4. Приёмка

- Ведомость на 160 строк появляется сразу, а не через минуты.
- Время создания — десятые доли секунды.
- Строки/позиции/метраж совпадают с XLS.
- Старые таблицы прошлого прогона удаляются до вставки новой.

## 5. Ограничения

- Нельзя менять число строк после создания — создавать заново.
- `SetText` — только после `AddTable` конечного размера.
- Объединение ячеек — до заполнения или в подавленном режиме.
- Для XLS используется SpreadsheetML; проверять `vl-file-size` после записи.
