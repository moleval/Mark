# legacy/ — архив прежнего процесса

| Папка | Что это |
|---|---|
| `tests/` | 15 исторических тестов 48.38–48.50; проверяют `backup/`, в приёмку не входят |
| `tools/build_single.py` | старый сборщик `MARK.lsp` из трёх исходников |

Сборщик больше не используется: `MARK.lsp` — единственный источник истины.
По умолчанию он **откажется перезаписывать** существующий `MARK.lsp`; для
принудительной пересборки нужен явный `--force`. `--check` только читает.

```bat
python legacy\tools\build_single.py --force   :: только осознанно
```

```bat
python legacy\tests\core_48_49.py
```

Возврат к сборке — только через исторический коммит/тег `pre-direct-mark`.
