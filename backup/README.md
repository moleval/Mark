# backup/ — исходники и исторический бэкап

Здесь лежат исходники, из которых собирается `MARK.lsp`:

| Файл | Версия | Роль |
|---|---|---|
| `MARKCORE.lsp` | Ред. 1.0 | ядро `mc:*` |
| `MARKZ.lsp` | Ред. 48.48 / 36.7 | заполнения |
| `MarkV.lsp` | Ред. 7.0 / 33.19 | каркас |
| `MarkV-bases.sample.lsp` | — | исторический образец внешней базы; **не загружается** |

## Важно

- Эти файлы **не загружаются** в AutoCAD для работы. Рабочий файл — `MARK.lsp`
  в корне.
- `MARK.lsp` не является простой склейкой: `tools/build_single.py` применяет
  производственные патчи (компактная шкала, чистка команд, отчёт, спецмарки,
  probe и т. д.).
- Правки логики — в `backup/` или в анкерах `tools/build_single.py`, затем
  `python tools/build_single.py`.
- Внешние базы больше не подхватываются; `MarkV-bases.sample.lsp` оставлен
  только как история.

## Бэкап

Старое состояние до слияния также доступно в истории Git и в теге
`pre-mark-lsp-48.48` (если тег создан). Эти файлы — «последняя отдельная
редакция» модулей.
